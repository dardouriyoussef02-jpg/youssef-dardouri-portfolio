# Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — responsive design, animations and theme
- `script.js` — menu, theme switcher, reveal animations and scroll progress

## Before publishing
1. Replace the `YOUR_EMAIL@example.com` placeholder in `index.html`.
2. Replace the LinkedIn and GitHub placeholder URLs with your real profiles.
3. Replace the GitHub button in the Travel4U project with the repository URL.
4. Add your CV as `assets/CV.pdf` if desired and change the button/link accordingly.

## GitHub Pages
Create a GitHub repository, upload these files to the repository root, then enable:
Settings → Pages → Deploy from branch → `main` → `/ (root)`.

The site is static, so no backend is required.
